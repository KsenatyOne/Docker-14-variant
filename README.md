# Музыкальный каталог — Docker Compose (Вариант 14)

Многокомпонентное приложение, состоящее из 4 независимых сервисов,
объединённых в единую bridge-сеть средствами **Docker Compose**.

**Вариант 14.**
- Web-сервис: *Музыкальный каталог — поиск музыкальных треков и исполнителей*.
- Данные для БД: *пользовательские плейлисты*.

## Архитектура

| Сервис       | Технологии              | Назначение                                                                 |
|--------------|-------------------------|----------------------------------------------------------------------------|
| `frontend`   | nginx + HTML/CSS/JS     | Веб-интерфейс с двумя функциональными кнопками. Доступен на порту `8080`.  |
| `backend`    | Python 3.12 + FastAPI   | REST API, CRUD к СУБД, интеграция с Web-сервисом.                          |
| `db`         | PostgreSQL 16           | Хранение сущностей, автоинициализация из `db/init.sql`, volume `pgdata`.   |
| `web-service`| Python 3.12 + FastAPI   | Локальный микросервис-эмулятор поиска треков и исполнителей.              |

### Схема взаимодействия

```
Браузер ──► frontend (nginx :80) ──/api/──► backend (FastAPI :8000) ──► db (PostgreSQL :5432)
                                                  │
                                                  └──► web-service (FastAPI :8080)  [поиск треков]
```

## Функциональность Frontend

- **Кнопка 1 — «Загрузить плейлисты из БД»**: `GET /api/playlists` (данные из PostgreSQL через Backend).
  Дополнительно: создание плейлиста, просмотр треков плейлиста, удаление плейлиста.
- **Кнопка 2 — «Найти треки»**: `GET /api/search?q=…` (данные от Web-сервиса через Backend).
  Найденный трек можно добавить в выбранный плейлист (`POST /api/playlists/{id}/tracks`).

## Запуск

Требуется установленный Docker с плагином Compose.

```bash
cp .env.example .env
docker compose up -d --build
```

После запуска откройте в браузере:

```
http://localhost:8080
```

Остановка:

```bash
docker compose down
```

Полная очистка вместе с данными БД:

```bash
docker compose down -v
```

## Переменные окружения (`.env`)

| Переменная          | Значение по умолчанию | Назначение                     |
|---------------------|-----------------------|--------------------------------|
| `POSTGRES_DB`       | `musicdb`             | Имя базы данных                |
| `POSTGRES_USER`     | `musicuser`           | Пользователь БД                |
| `POSTGRES_PASSWORD` | `musicpass`           | Пароль БД                      |

## API Backend

| Метод  | Путь                              | Описание                                        |
|--------|-----------------------------------|-------------------------------------------------|
| GET    | `/api/health`                     | Проверка доступности                            |
| GET    | `/api/playlists`                  | Список плейлистов (Кнопка 1)                    |
| POST   | `/api/playlists`                  | Создать плейлист                                |
| DELETE | `/api/playlists/{id}`             | Удалить плейлист                                |
| GET    | `/api/playlists/{id}/tracks`      | Треки плейлиста                                 |
| GET    | `/api/search?q=…`                 | Поиск треков/исполнителей (Кнопка 2)            |
| POST   | `/api/playlists/{id}/tracks`      | Добавить трек из Web-сервиса в плейлист         |

## API Web-сервиса

| Метод | Путь                 | Описание                                  |
|-------|----------------------|-------------------------------------------|
| GET   | `/health`            | Проверка доступности                      |
| GET   | `/search?q=…&limit=` | Поиск треков и исполнителей               |
| GET   | `/artists/{id}`      | Информация об исполнителе и его треках    |
